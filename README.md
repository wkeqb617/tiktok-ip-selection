## 三类 IP 差在哪：机房、原生、住宅双 ISP

先说结论式的分法：机房 IP 不能用，原生 IP 是及格线，住宅 IP 或双 ISP 才是能长期养号的那一档。

| IP 类型 | 归属信息显示 | TikTok 端的大致表现 | 适合拿来做什么 |
| --- | --- | --- | --- |
| 机房 IP（Datacenter） | 机房、云服务商 | 容易被判为非真人用户，轻则限流，重则封号 | 纯外链引流、不依赖自然推荐量的场景 |
| 原生 IP（Native） | 目标国家的本地注册信息 | 地理归属不矛盾，能正常拿到推荐流量 | 预算有限的起步账号 |
| 住宅 IP / 双 ISP | 某个家庭宽带运营商 | 看起来像真人在家里刷手机，风控敏感度最低 | 认真养号、直播、矩阵 |

**住宅 IP** 是运营商分配给家庭用户的地址，注册信息里的身份是居民用户，不是企业服务器。**双 ISP** 的实际形态是服务器仍放在机房，但 IP 段从运营商手里买来，对外表现为住宅属性，检测工具读出来是 ISP 类型，TikTok 同样按住宅网络处理。这也是目前多数“住宅 IP VPS”的实现方式。

**原生 IP** 只看一件事：IP 的注册地和机器的实际所在国是否一致。机房在洛杉矶、whois 也显示美国，就是原生。做美区用美国原生 IP，地理位置不打架，推流池才对得上。

有一类运营文章提到，TikTok 判断网络环境时会读 IP 的 ASN（自治系统编号），借此区分家庭宽带和机房托管，这个判断会牵连三件事：注册流程（ISP 网络下用安卓设备注册通常免邮箱验证，机房网络一般要走邮箱验证）、初始流量分配、风控触发的敏感度。TikTok 没有公开过这套规则文档，把它当作经验参考，别当成官方条款。

## 机房 IP 到底会差多少播放量

有推广文给出的对比是：同一套视频模板，ISP 住宅网络下新号基础播放 800～1000 次，机房 Hosting 网络下 300～500 次。另一批文章的说法更极端，直接是 0 播放、个位数播放。这两组数字量级对不上，没法合并成一个结论，只能说明方向：机房 IP 的起点明显更低，甚至拿不到初始推荐。

具体数字别当标准答案，它跟内容、账号历史、发布时间都有关系。真正稳定的是那条因果链：机房 IP 历史上被大量用于刷量和批量操作，天然带着风险标签，平台给的初始配额就低，而算法要不要继续往外推，是在这个起点上判断的。起点低一截，后面每一步都在还这笔账。

## 一个 IP 能挂几个 TikTok 号

安全做法是一个号一个 IP，不共用。

按风险分级看更直观：1 个账号属于标准配置，平台视为独立真实用户；2～3 个属于中高风险，短期可能没被发现，但关联隐患一直在；4 个以上基本等同于群控行为，封号只是时间问题。同一个出口 IP 下的账号，一个出问题，其他几个被连带处理的概率很高。

网上流传“一台机器挂 5 个关联度低的号”的说法，出处多是按台数卖机器的推广文，没有给出依据，放宽上限对它自己有利。真要跑矩阵，就按号数买机器，别在这上面省。

比 IP 更容易被忽略的是设备层。IP 只解决了网络身份，设备指纹、浏览器环境平台同样拿来判定关联。矩阵规模上来了，安卓模拟器或云手机选一种，再给每个号配独立的指纹浏览器环境，光换 IP 不换设备环境等于没做隔离。

## 静态还是动态，VPS 还是代理池

跑 TikTok 要静态 IP。动态 IP 每次连接都换地址，登录轨迹频繁跳跃，很容易触发异常验证；静态地址长期固定，符合真实用户的上网习惯。一个账号绑一个固定 IP，也就不会撞上“同账号多地登录”这条风控。

住宅 IP VPS 和住宅代理 IP 是两回事。VPS 是你独享一台服务器加一个固定住宅 IP，地址固定、独占、只有你在用；代理通常是共享 IP 池，地址会轮换，同一段 IP 上有多少人在跑什么业务你控制不了。养号这种需要账号长期绑定同一出口的场景，VPS 更合适。

## 下单前要确认的几件事

1. **IP 类型是不是真的住宅**。让商家给测试 IP，自己去 ipinfo.io 或 ipdata.co 查归属和类型，显示 Residential 才算过关，显示 Hosting 就是机房 IP 换了说法。
2. **是不是静态独享**。共享 IP 池、会轮换的地址，都不适合养号。
3. **地区对不对得上**。做哪个市场就买哪个地区的机器，别用一台机器跨区跑。
4. **退款期限**。同类商家普遍给 48 小时无理由退款，IP 质量好不好只有拿到手才知道，有退款窗口就等于可以试错。wepc.au 的具体条款以官网为准。

6. **流量和带宽**。短视频 100Mbps 够用，月流量按发布频率估；直播看的是上行稳定性，不是标称带宽数字。

## 机器到手还是 0 播放：按这个顺序查

IP 买对了只是第一步。下面几条是前排文章普遍讲得浅、但实际最容易翻车的地方。

**时区、语言和 IP 三者必须一致。** 用美国 IP 注册，手机时区设成美国时区，系统语言设成英语。三者不一致，平台会判定环境异常，直接限流。这一条比换 IP 还容易被忽略。

**选定地区就别换来换去。** 今天美国 IP、明天英国 IP，账号会被判为异常登录。要跑新市场，开新号配新机器。

**新号先养 3～5 天。** 注册完先刷视频、点赞、评论，模拟真人行为，再开始发自己的内容，0 播放的概率会低不少。

**自己验 IP 纯净度。** ipinfo.io、ipdata.co 看归属类型，Scamalytics 或 IPQS 看欺诈分值，越接近 0 越好。商家说欺诈值为 0，拿到手自己验一遍，一分钟的事。

**顺手查 DNS 和 WebRTC 泄漏。** 代理配好了但 DNS 还在走本地，真实位置一样会暴露。指纹浏览器里把时区、语言、分辨率跟着 IP 地区设一遍。

**设备环境独立。** 每个号一套独立的浏览器指纹环境，矩阵规模大了用云手机统一管理。
